### Harapan UI mengenai portofolio
* 1. Connect dengan Linkedin
Connect bukan sekedar menghubungkan koneksi pengunjung ke pemilik portofolio, harapannya Experience, Education, License & Sertificate, dan Projects dapat terhubung dan ditampilkan ke Portofolio. Artinya si pemilik yaitu aiyub heriyanto ketika menambahkan sesuatu dari beberapa fitur tersebut akan otomatis terupdate juga di portofolio, contoh jika si pemilik menambah sertifikat baru maka portofolio akan menambah sertifikat baru juga secara real time

* 2. Teks judul yang tidak rapi
Teks judul pada bagian skill yang berisi " Area teknis yang sedang saya bangun dengan serius. " dan bagian project yang berisi " Proyek dan pengalaman yang membentuk cara saya bekerja. " terlalu ke kanan sebaiknya di letakkan di kiri dan memanjang ke kanan, jika di gambarkan padding bagian judul tersebut dibuat seperti kotak persegi panjang

* 3. Menu Gallery
Bagi pengunjung perlu adanya Gallery yang dibuat menggunakan Konsep Image Slider, dan bagi pemilik jika sewaktu-waktu ingin menambahkan gambar baru maka cukup dengan menambahkan tag html yang digunakan untuk Image slider sehingga CSS maupun JS yang digunakan untuk Image Slider dibuat dinamis jika ada penambahan tag html Image Slider, contoh kasusnya: jika struktur awal image slider hanya ada 5 maka pemilik bisa menambahkan tag html image slider baru tanpa harus mengubah styling css maupun file JS. Gunakan panorama slider dari https://uiinitiative.com/catalog/panorama-slider

* 4. Komentar Gallery
Selain menunjukkan gambar pada image slider, ada judul gambar dan deskripsi singkat mengenai setiap gambar yang ada di image slider

* 5. Intro Animation
Setiap berpindah ke menu tertentu ada animasi intro halus, untuk animasi bebas tapi tidak perlu animasi yang benar benar mencolok
